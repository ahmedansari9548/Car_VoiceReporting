# ─────────────────────────────────────────────────────────────
# PSYCOPG 2 → 3 MIGRATION
#
# Your session_repo.py currently imports psycopg2. On Python 3.14 you
# have two options:
#
# OPTION A — switch to psycopg 3 (recommended, keep the line above):
#     import psycopg
#     from psycopg.rows import dict_row
#
#     # old: conn.cursor(cursor_factory=psycopg2.extras.RealDictCursor)
#     # new: conn.cursor(row_factory=dict_row)
#
#     Everything else (execute, fetchone, commit) works unchanged.
#
# OPTION B — stay on psycopg2. Replace the psycopg line above with:
#     psycopg2-binary>=2.9.10
#     ...and if pip fails to find a wheel, you'll need build tools:
#         Ubuntu:  sudo apt install libpq-dev python3-dev gcc
#         Windows: install PostgreSQL, then pip install psycopg2
# ─────────────────────────────────────────────────────────────
